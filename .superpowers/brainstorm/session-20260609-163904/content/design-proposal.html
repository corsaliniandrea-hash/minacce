Proposta di design — "Grunge Distrutto"

1. Filtro SVG potenziato

Rimpiazzo il filtro #noisy-text attuale con uno più aggressivo:

  • feTurbulence: baseFrequency 4.0 (ora 1.8), numOctaves 4 (ora 3) — più rumore
  • feDisplacementMap: scale 25 (ora 10) — bordi più frastagliati
  • Aggiungo feMorphology: dilata/erode sottile — bordi "mangiati"
  • Aggiungo feColorMatrix: contrasto sporco, opacità variabile

2. Distorsione JavaScript dei path

Uno script che modifica i path SVG a runtime:

  • Ogni vertice (M, L, C, S) viene spostato casualmente
  • Jitter progressivo: più forte sui bordi destro/inferiore
  • Ogni 5-10 secondi i path "tremano" per dare vita

3. Maschere di distruzione

Uso clip-path/mask SVG per rimuovere pezzi di lettere:

  • Macchie casuali che "mangiano" parti del testo
  • Si aggiornano lentamente ogni 3-4 secondi
  • Aree con più rumore hanno più buchi

4. Texture integrate

  • Doppia texture noise sovrapposta (mix-blend-mode: multiply)
  • Sporco, graffi, linee casuali generate via Hydra/Canvas
  • Particelle che si staccano dai bordi (opzionale)

Effetto finale atteso

La scritta "MINACCE" sembrerà corrotta, distrutta, grunge — come se fosse stata dipinta su un muro 20 anni fa e poi parzialmente cancellata dal tempo. Gli effetti dinamici (tremolio, buchi che si spostano) daranno una sensazione di decadenza "viva".
